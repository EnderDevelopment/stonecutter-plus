# StoneCutterPlus

StoneCutterPlus is a Minecraft plugin that enhances the vanilla stonecutter by allowing players to input stone and cut it into andesite, diorite, and granite. This plugin adds a new functionality to the stonecutter, making it more versatile and useful for players who want to quickly obtain different types of stone.

## Install

1. Download the plugin JAR file from the releases section of this repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server.

## Use

1. Open a stonecutter by right-clicking on it.
2. Place a stack of stone in the input slot.
3. Select the desired output type (andesite, diorite, or granite) from the recipe selection.
4. Take the output items from the result slot.
